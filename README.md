# 📈 Trading Academy — Day Trading Practice Platform

**Trading Academy** is an interactive, beginner-friendly web application designed to teach the fundamentals of day trading, risk management, chart analysis, and market mechanics — using **100% virtual funds**.

## 🌟 Key Features

### 🎓 Structured Learning Path
* **5 Progressive Levels:** Unlock lessons sequentially by mastering core concepts:
  1. **Trading Basics:** Stocks, shares, day trading, bid/ask prices, and P&L fundamentals.
  2. **Risk Management:** Stop-loss orders, planned vs. actual loss, unrealized vs. realized profits, and slippage.
  3. **Trading Calculations:** Profit/loss calculations, risk-to-reward ratios, position sizing, and trading fees.
  4. **Charts & Market Mechanics:** Candlestick patterns, price action, support/resistance, and volume.
  5. **Practice & Review:** Simulated scenarios, risk management challenges, and final assessment.

### 📝 Interactive Quiz Engine
* Multiple-choice assessments at the end of each lesson.
* Instant step-by-step explanations for correct and incorrect answers.
* Automatic retry mechanism for missed questions.
* **"My Mistakes" Engine:** Keeps track of incorrectly answered questions for targeted review and retaking.

### 📊 Virtual Trading Simulator
* Start with a **$10,000 virtual cash balance**.
* Real-time interactive candlestick price charts with timeframe toggles (1m, 5m, 15m, 1D).
* Simulated market, limit, and stop-loss orders.
* Complete order history and active portfolio tracking.
* **Zero real-world financial risk.**

### 🧮 Built-in Position & Risk Calculator
* Calculate loss per share, total planned loss, purchase cost, and price change percentage before placing trades.
* Takes optional fee estimates into account.

### 🏆 Progress & Achievement System
* Student dashboard tracking learning levels, streak counts, completed lessons, and quiz scores.
* Earnable badges and achievements (e.g., *First Step*, *Risk Manager*, *Chart Master*).
* Automatically saves progress locally via browser storage (`localStorage`).
